# The keys grid around the mic button. Easiest: right-click the mic > "Edit layout (drag and drop)".
# Or edit this file by hand: save it and the buttons change at once.
#
# Each [Name] line starts a layout; tabs on top of the grid switch between them.
#   grid = 5 x 4              columns x rows of the layout below it
#   columns = 5               columns only; rows grow as needed (before the first [Name]: for every layout)
#   -                         a line with just - ends the current row early (for buttons without "at")
#
# One button per line:
#   Label | keys | the keys to press        several in a row: separate with spaces, e.g.  {Home} +{End} ^c
#   Label | text | text to type
#   Label | open | program, folder, file or web address   (a program's or file's own icon is shown)
#   Label | hold | Ctrl  or  Shift  or  Alt  stays held for your next key or click; tap again to let go
#                                         add "sticky" to keep it held until tapped again
#   Mic   | mic                       the mic button, 2 x 2 unless a size says otherwise
#                                     (no Mic line: one extra column, the mic at the bottom right)
#   Touchpad | touchpad              a touchpad: slide = move the pointer, tap = click, two-finger tap or
#                                    hold = right click, tap then slide = drag (2 x 2 unless a size says otherwise)
# Then, in any order, any of:
#   E8C8                      an icon from the Segoe Fluent Icons font, as its 4-character code
#   at 3,2                    column 3, row 2, counted from 1 at the top left; without it: the next free spot
#   size 2x1                  2 spots wide, 1 tall (default 1x1)
#   repeat on / repeat off    whether holding the button repeats it; without it, single keys like arrows repeat
# The label may be left empty when there is an icon:   | keys | {Up} | E74A
# Key names: ^ Ctrl  + Shift  ! Alt  # Win   {Enter} {Tab} {Esc} {Del} {BS} {Home} {End} {PgUp} {PgDn}
#            {Up} {Down} {Left} {Right} {F1}..{F12} {Space}
# Folders and files: %USERPROFILE%, %LOCALAPPDATA% and other Windows variables work.
# Lines starting with # are notes. The editor keeps this block and rewrites everything below it;
# the file before its last save is kept as layouts.bak.
